# IDE Application Template

A high-performance Android application foundation built with Kotlin 2.0+, ViewPager2 hardware-accelerated navigation, Material 3, and automated GitHub Actions Cloud CI builds.

## Quick Documentation Links
- **[PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)**: Full project context, architecture overview, user preferences, and app modification guide.
- **[GEMINI.md](GEMINI.md)**: AI agent environment rules, zero-emoji policy, and cloud build constraints.

## Cloud CI Build Flow
All builds are managed via GitHub Actions cloud runners (`.github/workflows/build-android.yml`). No local compilation tools (Gradle/Java) are installed or needed on the host development machine.
